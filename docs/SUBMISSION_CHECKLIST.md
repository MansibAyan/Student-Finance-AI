# Submission Assembly Checklist

## Required materials
- Technical documentation: `docs/TECHNICAL_DOCUMENTATION.md` and `.docx`
- Presentation deck: `presentation/Student_Finance_AI_Competition_Deck.pptx`
- Source and deployment notes: root `README.md`, `workflow/`, and `db/`
- Security self-assessment: `docs/SECURITY_SELF_ASSESSMENT.md` and `.docx`
- Test cases: `tests/TEST_PLAN.md`
- Execution evidence: `evidence/` (attach actual dated, redacted staging outputs)
- Demo video: optional, maximum 5 minutes under the rules document

## Final owner actions
- Add the repository URL and ensure reviewers can access it.
- Include the complete schema/migration set matching the target database where permitted.
- Bind private credentials only in n8n/Supabase; keep them out of the ZIP and public repository.
- Run and record the tests relevant to the features shown in the presentation.
- Confirm team eligibility, registration details, submission channel, and receipt with the organizer.
- Keep the final presentation within 10 minutes.
